💾 Your work

Download as .ipynb to open later in Jupyter, VS Code, or Colab — or re-open a notebook here with Open .ipynb. Everything stays on this device.

Kernel: CPython via Pyodide 0.26.4 (WebAssembly). Variables persist between cells until you restart the kernel, just like Jupyter. No code leaves your browser — there is no server executing it. If a cell is taking long, restart the kernel to reset state. Cells can also read data straight from a URL — e.g. pd.read_csv("https://…") — fetched by your browser, so the host has to allow cross-origin (CORS) access.
